# 34 — A position for every move that has one

Improvement 2 of the eight agreed on 2026-11-23.

- A move is now placed on the map (and on its case page) by three things, first mention first: the
  features its description names (as before); the features its accepted events' places name; and its
  events' own coordinates, which is where a position the coder gives through "Edit: lat/lon" in
  Airtable ends up. So setting a position on a new move needs no new field.
- Four one-word names of single features now count: Thitu, Pag-asa (Pagasa), Triton, Panata.
  Thitu Island's map name was its Filipino one (Pag-asa Island); it is now Thitu Island.
- 158 of 388 moves are placed (was 144). The other 230 name no particular place ("287 features",
  "the Spratlys", "disputed waters", a statement in a capital): they count on their sub-regions, and a
  point for them would be invented, so none is made up.
