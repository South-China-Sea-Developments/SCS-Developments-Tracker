# 15: Site restyle

**What to build:** The public site reads as an institutional research publication rather than a generic dashboard, with one coherent visual system across every page, a home page that leads with the story and the map, and design tokens arranged so the Asia Society Policy Institute's own type and colours can be dropped in without rework when the site moves to their hosting. The maintainer chose (2026-10-26): match ASPI's visual language; home page = narrative lede + headline numbers + latest developments, with the map taking most of the page; the whole site in one pass.

**Blocked by:** 08, 09

**Status:** done (2026-10-26). The institutional default tokens were replaced the same day by values read from three references the maintainer supplied (ticket 16).
