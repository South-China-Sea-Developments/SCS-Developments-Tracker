# 05. Canonical storage

**Depends on:** 04. **Blocks:** 06, 08.

**Question.** Where does the canonical data live (versioned files in this repo, a hosted database, a spreadsheet tool), and what is the review and merge workflow?

**Settled 2026-10-15:** versioned CSV/GeoJSON files in this repository; review queue as pull requests; Airtable optionally as the review front end only. See ADR 0004.
