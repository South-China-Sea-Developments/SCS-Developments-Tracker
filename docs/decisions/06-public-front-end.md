# 06. Public front end

**Depends on:** 05.

**Question.** Reproduce MAVD's layout, or build a new map + charts + case browser; which features; where hosted?

**Settled 2026-10-15:** MAVD-equivalent views (so the 1970–2015 comparison holds and doubles as a data-loading check) **plus an event layer**: real event points with time filtering, per-claimant timelines distinguishing moves from their events, filters by Type/Domain/Issue/Dyad, a case browser with sources as links, and a Downloads page with CSV, GeoJSON and a citation at a tagged version.

Visual style is free (need not resemble MAVD); the requirement is clear, clean, comprehensive, well organised. *Added 2026-10-26 (ticket 15): the maintainer chose to match the Asia Society Policy Institute's visual language — adopted as type and colour tokens in one block of the stylesheet, so their values drop in when the site moves to their hosting; the institute's name, logo and wordmark are theirs to add and appear nowhere in the site's pages, styles or assets — with a home page that leads with the narrative, headline numbers and the event map taking most of the first viewport, then the latest developments.* *Added 2026-10-26 (ticket 16): the maintainer supplied three references to copy more closely — the institute's "South China Sea Research Initiative" banner, its Center for China Analysis article pages, and the MAVD dashboard — and the site now takes its display face, its sea-coloured hero and its dark map panel from them; their name, logo, lion mark, wordmark and photograph still appear nowhere (the sea in the hero is drawn).* *Amended 2026-10-27 (ticket 17): the maintainer asked for the institute's own banner (logo and title) as the site header and for its colours, so the site now presents itself as the Asia Society Policy Institute's; the rule that kept the identity out is withdrawn. He also asked that nothing on the site describe the project's progress: pending moves are not published, and no page says how many claimants or moves are coded. The home page follows CFR's Global Conflict Tracker (sidebar beside a full-height dark map) and there is one colour scheme.* The site will later be hosted on the ASPI website, so it is built as a **portable static bundle** (relative paths, no dependency on GitHub Pages features) that can be dropped onto any web host; GitHub Pages is the interim host.
