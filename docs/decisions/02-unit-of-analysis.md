# 02. Unit of analysis for new data

**Depends on:** 01. **Blocks:** 04, 05, 06.

**Question.** One row per MATS move with dates and coordinates added, two linked levels (move + event), or events only?

**Settled 2026-10-15:** two levels. Move = MATS unit (a year-on-year intensification); Event = dated, located, sourced incident, each belonging to one move. See ADR 0002.
