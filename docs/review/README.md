# Review pages

One self-contained HTML page per harvest run, generated by `python -m pipeline.queue open` on the run's branch (`harvest/<run_id>`) and committed with the candidates. Open it from the checked-out branch in a browser: it lists every candidate with its source excerpt and link, the extractor's suggested coding and reasoning, duplicate flags, and the claimant's moves from the previous year and the current year. Decide each candidate (merge into an existing move, form a new move with its intensification criterion, or reject with a note), export `decisions.json`, and apply it:

```
python -m pipeline.queue decide decisions-<run_id>.json --reviewer "Your name"
git push
```

The page writes nothing itself; only `decide` changes the files, and only a merged pull request changes the dataset. Drafts are kept in the browser's local storage until exported. Pages here are kept with the run they belong to; they can be regenerated with `python -m pipeline.queue page --run-id <run_id>`.
