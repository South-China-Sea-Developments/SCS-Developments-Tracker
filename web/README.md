# Public site

A self-contained static bundle built from `data/*.csv` by `python -m web.build`. No framework, no build chain: Jinja2 templates, one stylesheet, one script, one vendored font (Instrument Sans, OFL). Relative paths only, so the output folder can be dropped onto any host (GitHub Pages for now; ASPI later) or opened from disk.

## Pages

- `index.html` overview; `issues-domains.html` (issue and domain mentions by year, by claimant and by sub-region); `subregions.html` (choropleth by period with a claimant selector, moves by sub-region and type, one chart per sub-region over time); `cases.html` searchable case browser (client-side filtering of an inline index); `cases/<move_id>.html` one page per move with coding, events, sources and an inset map of the sub-regions (simplified polygons inlined, ~1 KB); `map.html` event map (MapLibre GL, vendored; events, polygons and the basemap style inline, the events also written to `data/events.json`; OpenFreeMap's vector tiles, fonts and sprites are the only external requests — free, no key, no stated limits; the bundled style `web/static/vendor/openfreemap/positron-en.json` labels everything in English/Latin script, and the tile URL inside it is the one line to change for another tile host); `methodology.html` (codebook summary, provenance, how to cite, and the machine–human agreement report, also written to `data/agreement.json`); `downloads.html` (the files at the latest release tag, with checksums, served from `downloads/` inside the bundle, plus citations in text, BibTeX and CFF).

## Design notes

Subject: a research dataset about contested waters. Audience: researchers, analysts, journalists. Job: trends at a glance, then down to the evidence.

- **Identity device:** the masthead carries a faint graticule, a nod to hydrographic charts. It is the only decoration; everything else is data and type.
- **Type:** Instrument Sans throughout, one family; headline weight 600 with tight tracking; no all-caps labels, no eyebrows.
- **Colour:** page plane is a pale hydrographic tint, surfaces near-white, ink blue-black. Claimants use the dataviz categorical palette in fixed slot order (China, Vietnam, Philippines, Malaysia, Indonesia, Taiwan) so a filter never repaints survivors. Move types are an ordered intensity scale and use one blue ramp, pale (declarative) to dark (use of force). Issues and domains use the categorical slots in fixed order on their own page. The choropleth uses the sequential blue ramp, reversed in dark mode so zero recedes toward the surface. All palettes validated with the dataviz validator in light and dark mode.
- **Marks:** stacked columns ≤ 24px wide, 4px rounded data-end, surface-coloured gaps between segments (2px, 1px when bands are narrow), hairline solid gridlines, muted axis ticks, tabular figures on ticks and in tables.
- **Pills in the case list:** a dashed pill marks a move pending the author's confirmation; a solid pill marks project coding (any move not from MATS 1.02), so the two provenances never pass for one another.
- **Case browser filters:** within a group (type, domain, issue) any checked value matches; across groups all must match; the claimant chips are a show/hide set like the overview's, so unchecking all shows nothing.
- **Interaction:** one hover tooltip per column (values lead, labels follow, line keys), keyboard focus shows the same; one filter row above everything it scopes; every chart has a table-view twin (the WCAG-clean equivalent, and the relief for the light-mode hues under 3:1 contrast: Philippines, Malaysia, Indonesia and the declarative step). Keyboard users read the table; the column hit targets are pointer-only so a chart is not 46 tab stops.
- **Event map:** events are the move's colour (claimant); a filled disc has its own coordinates, a hollow one stands at a named feature; events sharing a position stack into one disc carrying their count; unplaced events are a neutral count pill on their sub-region. The basemap is OpenFreeMap's Positron with English-only labels (a Chinese, Thai or Vietnamese label would be a second script competing with the data), desaturated in light mode and inverted-and-retoned in dark mode so the data stays the loudest thing on the map. Time is one month slider plus a window selector rather than a two-handle range: one control, and "the year ending here" is how the dataset thinks.
- **Responsive:** columns shrink to a 5px band before the chart scrolls (46 years fit a phone); if it must scroll it opens at the latest years with a fade on the left edge. Small multiples go to one column below 440px.

Tried and rejected: three-column small multiples on desktop (bands too thin to read); hover targets only on years with data (a year with none should still answer); an 8px minimum band on phones (hid 2007–2015 behind an unsignposted scroll); focusable column hit targets (184 tab stops per page).
