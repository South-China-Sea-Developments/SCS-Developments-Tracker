Reading the map

A point is one event: a patrol intercept, a statement, a drilling start, dated and sourced on its move's page. A filled point has coordinates of its own; a hollow point stands at the named feature (reef, shoal, island) the sources mention, placed with the project's gazetteer. Where the sources name only a wider area, or the original dataset recorded no place, the event is counted on a sub-region instead: its own if one is known, otherwise once on each sub-region of its move, so the numbers on the ten polygons can add up to more than the number of events. The filters use the move's coding (type, domain, issue, counterpart), because MATS variables belong to the move, not the event. The base map is drawn from OpenFreeMap vector tiles (OpenMapTiles schema, © OpenStreetMap contributors, ODbL) with English names in the Latin alphabet wherever the data has them; the tiles and their fonts are the only things on this page not in the bundle, and without them the sub-regions and events still draw. Boundaries and names on the base map are those of its providers; the feature names this project uses follow the source text and Wikidata's English labels; neither implies a position on any claim.
