How to read this

A move is a step up in one claimant's assertiveness on the year before, coded with the rules of the Maritime Assertiveness Time Series. Each bar is a year; each segment a move, by claimant or by type. Types run from declarative statements to the use of force, pale to dark.

How to read this

Each move is tagged with the issues it addressed (military, administrative, energy, fisheries, politics) and the domains it played out in (domestic, diplomatic, physical). A move can carry several, so these charts count mentions: a move about both energy and fisheries counts under both. The full definitions are in the methodology.

How to read this

MATS places each move in one or more of ten sub-regions. A move that spans several is counted in each of them, so the sums across sub-regions overstate the number of moves. The map shows the same sub-regions, period by period.
